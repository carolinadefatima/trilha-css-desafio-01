# Desafio DIO: Landing Page Responsiva (HTML e CSS)

Este projeto marca a consolidação dos meus fundamentos de Front-End na Trilha CSS da DIO.

## Objetivo Técnico

O principal objetivo foi praticar a conversão de um **layout estático (Figma)** em uma **estrutura de código responsiva e modular**. O foco esteve na **separação clara de responsabilidades** (HTML para estrutura, CSS para estilo) e na aplicação de técnicas de **design responsivo** para garantir a usabilidade em diferentes dispositivos.

## Tecnologias e Conceitos Aplicados

* **HTML5:** Uso de marcação **semântica** para melhor acessibilidade e SEO.
* **CSS3:** Aplicação de conceitos avançados como:
    * **Design Responsivo** (Media Queries).
    * Uso estratégico de **propriedades gradientes** e multi-camadas.
    * Estilização de elementos customizados (botões).
* **Versionamento:** Uso de Git/GitHub para o controle do fluxo de desenvolvimento.

## Habilidades Transferíveis para Full Stack

Este projeto estabelece o pilar visual para a jornada Full Stack, garantindo que o Back-End entregue dados a uma interface bem estruturada:

* **Estrutura de Componentes:** Embora seja CSS puro, a estruturação de seções estabelece o raciocínio para a **componentização** futura em React.
* **Atenção aos Detalhes:** Habilidade crucial de replicar *pixel-perfect* (precisão visual), que se traduz em **garantia de qualidade (QA)** em sistemas Full Stack.
